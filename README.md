# Residencial Los Robles - Sistema Web de Gestión

Portal web integral para residentes de **Residencial Los Robles**, que permite la consulta y pago de cuotas de mantenimiento, gestión de avisos y contacto directo con la administración.

## Tecnologías Utilizadas
* **Frontend:** React.js, JavaScript (ES6+), HTML5, CSS3.
* **Metodología:** Scrum.
* **Control de Versiones:** Git & GitHub.
